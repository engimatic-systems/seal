* Contract repair and friction

The first live =init= attempt exposed a contract-blocking lifetime defect:
successful initialization printed corrupted prefixes for both returned paths.
Odin =defer= is block scoped; cleanup deferred inside two completed =if= blocks
freed the paths before the following diagnostics used them. Car 006 moves the
conditional deletes into one procedure-scoped deferred block in =SEAL.org= and
the tangled =seal/init.odin=. The fixed transcript above proves the repair.

Observed non-blocking friction:

- Global =--debug= applies the specified default =-v= to both rsync and SSH, so
  exact-plan evidence includes substantial OpenSSH diagnostic output.
- The peer's ordinary environment found rsync at
  =/run/current-system/sw/bin/rsync=; no =--rsync-path= expansion was needed.
- The ignored tangle helper was absent from this later-car worktree, requiring
  an explicit path to the existing Odin helper.
- Rebuilding unchanged source produced a different binary SHA-256. Live
  behavior and required compiler/test results were stable, but binary-byte
  reproducibility was not established.

No command, option, transfer flag, VM machinery, or mailbox interpretation was
added.
