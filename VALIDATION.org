* Observed Friction

- Host shell still had no Cargo: direct =cargo build= failed with status =127=
  and =zsh:2: command not found: cargo=. Recorded Nix toolchain built cleanly.
- First Nix toolchain entry unpacked the =nixpkgs-unstable= expression archive
  into its Git cache before building. This was transient environment hydration,
  not a Seal failure.
- An auxiliary zsh cleanup recheck initially used lowercase =path= as a loop
  variable. Because zsh ties =path= to =PATH=, following =ssh= and =git=
  lookups failed with status =127=. A fresh shell and neutral variable name
  completed the recheck; the live cleanup results above were unaffected.
- Default SSH debug =-v= makes =--debug= output much longer than Seal's exact
  structured process plan.
- Remote mailbox creation remains a separate operator step. This matched the
  v0 contract and did not block use.
- Remote rsync discovery through the peer's ordinary environment worked.
- Stabilized rsync =--rsh= encoding worked live: pinned SSH was one quoted word
  followed by =-v --=, while rsync retained its own =--= before operands. No
  contract-blocking defect or implementation change was needed.
